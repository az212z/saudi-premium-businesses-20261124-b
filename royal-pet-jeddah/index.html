الرعاية الطبية

الكشف والمتابعة والعلاج لأليفك، مع فريق يشرح لك الحالة والخطوة التالية بوضوح.

الجراحة

عمليات جراحية داخل العيادة، مع متابعة بعد العملية حتى يتعافى أليفك.

قبل أول زيارة، أحضر معك

  • كرت التطعيمات إن وُجد.
  • أي تقارير أو تحاليل سابقة.
  • حقيبة نقل للقطط، ورباطاً للكلاب.
  • اسم الطعام الذي يأكله أليفك حالياً.

متى تتصل فوراً ولا تنتظر الموعد

هذه علامات تستدعي الاتصال بالعيادة مباشرة:

  1. صعوبة في التنفس، أو لثة شاحبة أو زرقاء.
  2. الاشتباه بتناول مادة سامة أو دواء بشري.
  3. قطة ذكر تحاول التبول ولا يخرج شيء.
  4. نزيف لا يتوقف، أو إصابة بعد سقوط أو حادث.
  5. قيء أو إسهال متكرر مع خمول واضح.
